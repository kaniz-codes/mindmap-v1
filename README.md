# MIND MAP

MIND MAP is a student planning and scheduling system designed to help university students manage classes, tasks, extracurricular activities to schedule and add reminder efficiently. 

It focuses on schedule awareness, free-time detection, conflict checking, and structured goal planning.


## Overview

MIND MAP is designed for university and college students who need to manage academic and personal responsibilities together.

The system combines:

- Class routines
- Academic and personal tasks
- Extracurricular activities
- Personal goals
- Progress tracking
- Reminders
- Free-time detection
- Schedule conflict detection
- Missed-task rescheduling
- AI-assisted goal planning


## The Solution

MIND MAP maintains a unified schedule for each student.

Classes, extracurricular activities, goals, reminders, and related information are stored as structured data. The system can then use this information to understand occupied time, calculate available time, detect schedule conflicts, and support rescheduling decisions.

AI is used mainly for planning assistance, such as generating editable goal roadmaps.
