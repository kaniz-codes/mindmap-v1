MIND MAP is a student planning and scheduling system designed to help university students manage classes, tasks, extracurricular activities, reminders, and personal goals more efficiently.

It focuses on schedule awareness, free-time detection, conflict checking, missed-task rescheduling, and structured goal planning.

## Overview

MIND MAP is designed for university and college students who need to manage academic and personal responsibilities together.

The system brings the following into one platform:

- Class routines
- Academic and personal tasks
- Extracurricular activities
- Personal goals
- Progress tracking
- Reminders
- Free-time detection
- Schedule conflict detection
- Missed-task rescheduling
- AI-assisted goal planning


## How It Works

MIND MAP keeps a structured record of a student's classes, tasks, activities, goals, and reminders.

Using this information, the system can identify occupied and available time, detect scheduling conflicts, and support task rescheduling. AI assistance is used for planning features such as generating editable roadmaps for long-term goals.
